# Tubes

The web app of Tubes. It has two looks, on purpose:

- **Watching** (`src/watch/`): the old Tubes look, a video site's layout drawn with Tubes' own
  mark and `tube-*` tokens (`src/styles/tube.css`): a top bar with the search box, a rail of
  pages and channels, rounded thumbnails with the running time, "views · age" under each title.
  - **Home**: a chip per channel over the newest videos, read a page at a time as the page scrolls.
  - **Search** and **Channels**: results as wide rows; every channel as a round picture; a
    channel's page with its videos, a page at a time over a cursor (`useInfiniteLoad`).
  - **Watch**: opening the page is the play; the frame says what it waits for while the first
    seconds arrive, then hls.js plays the copy as it grows. Up next sits beside it.
- **Admin** (`src/screens/`, under `/admin`): [strata-react](https://github.com/jburnhams/strata-react)'s
  look and rules, for running the server.
  - **Cache**: `Meter` against the trimming line, `DataTable` with the sort in the URL, `RowAction`
    Pin and Delete (`useUndoable` + `UndoBar`), Trim now (`AsyncButton`).
  - **System**: a polled status read with `StaleNotice`, `Status` words, a `Meter` with named
    thresholds, Sync now, `LinkCard`s.
  - **Settings**: `Tabs` with the tab in the URL, a form started from the server's values,
    `ColorSchemeChoice`.

Each story is a whole screen, opened through the app's own route tree at a URL, with the server put
into one state by MSW (the same handlers the jsdom tests and the visual suite use). Use the toolbar
to switch between light and dark.

Every story is screenshotted in Chromium, light and dark, and compared with a committed baseline in
CI (`npm run test:visual`). Stories tagged `no-visual` need a click to reach their state, or draw
something that changes from run to run (a playing video); the route shots in
`strata-visual.config.ts` cover the clicks.
